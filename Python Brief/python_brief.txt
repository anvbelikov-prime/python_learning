Регулярыне выражения:
import re

re.compile(<регулярное выражение>, <модификаторы>) - скомпилировать шаблон регулярного выражения

^ - привязка к началу строки
$ - привязка к концу строки

Полезные модификаторы:
re.M - поиск в многострочной строке
re.I - игнорировать регистр символов
re.S - "точка" соответствует любому символу, включая символ перевода строки \n

pattern = re.compile(r'^[a-z]+$', re.I | re.M)
pattern.search(text_for_searching)    # проверяет совпадение шаблона с любой частью строки, отдает объект Match
pattern.match(text_for_searching)     # проверяет совпадение шаблона с началом строки, отдает объект Match
pattern.findall(text_for_searching)   # список найденных совпадения с шаблоном

[13] - цифра 1 или 3
[abc] - символ a или b или c
[a-z] - символ из диапазона символов от a до z
\d - цифра
\s - пробельный символ (любой)
\w - эквивалентно [a-zA-z0-9_]
\D - отрицание от \d
\W - отрицание от \w
\S - отрицание от \s

{n} - n вхождений
{n,} - >= n вхождений
{n,m} - от n до m вхождений
* - 0 или больше вхождений
+ - 1 или больше вхождений
? - ни одного или 1 вхождение

def fib_gen(lim=10):
    i = 0
    a, b = 0, 1
    while i <= lim:
        if i == 0:
            yield a
        elif i == 1:
            yield b
        else:
            b, a = a + b, b
            yield b
        i += 1

Итератор должен реализовывать методы __iter__ и __next__. StopIteration - это сигнал о том, что элементы кончились.

Примеры:
it = iter([1, 2, 3])

while True:
    try:
        i = next(it)
        print(i)
    except StopIteration:
        print('Stoped! No other elements in sequence!')
        break

it = [1, 2, 3].__iter__()

while True:
    try:
        i = it.__next__()
        print(i)
    except StopIteration:
        print('Stoped! No other elements in sequence!')
        break

Делегирование итерации:
class MyContainer:
    def __init__(self, val=0, seq=[1, 2, 3]):
        self.val = val
        self.seq = seq
    def __iter__(self):
        return iter(self.seq)  # делегируем "родному" методу iter класса последовательности

Также можно использовать функцию-генератор для итерации по ее результатам:

Пример:
def my_range(start=0, stop=10, inc=0.5):
    cur = start
    while cur <= stop:
        yield cur
        cur += inc

Реализация протокола итератора:

class IterCLass:
    def __init__(self, seq=[1, 2, 3]):
        self.idx = 0
        self.seq = seq
    def __iter__(self):
        return self
    def __next__(self):
        if self.idx < len(self.seq):
            self.idx += 1
            return self.seq[self.idx - 1]
        else:
            self.idx = 0
            raise StopIteration

Пример с функциями-генераторами для __iter__ и __reversed__:

class Countdown:
    def __init__(self, start):
        self.start = start
    def __iter__(self):
        n = self.start
        while n > 0:
            yield n
            n -= 1
    def __reversed__(self):
        n = 1
        while n <= self.start:
            yield n
            n += 1
