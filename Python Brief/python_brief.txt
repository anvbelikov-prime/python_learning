Регулярыне выражения:
import re

re.compile(<регулярное выражение>, <модификаторы>) - скомпилировать шаблон регулярного выражения

^ - привязка к началу строки
$ - привязка к концу строки

Полезные модификаторы:
re.M - поиск в многострочной строке
re.I - игнорировать регистр символов
re.S - "точка" соответствует любому символу, включая символ перевода строки \n

pattern = re.compile(r'^[a-z]+$', re.I | re.M)
pattern.search(text_for_searching)    # проверяет совпадение шаблона с любой частью строки, отдает объект Match
pattern.match(text_for_searching)     # проверяет совпадение шаблона с началом строки, отдает объект Match
pattern.findall(text_for_searching)   # список найденных совпадения с шаблоном

[13] - цифра 1 или 3
[abc] - символ a или b или c
[a-z] - символ из диапазона символов от a до z
\d - цифра
\s - пробельный символ (любой)
\w - эквивалентно [a-zA-z0-9_]
\D - отрицание от \d
\W - отрицание от \w
\S - отрицание от \s

{n} - n вхождений
{n,} - >= n вхождений
{n,m} - от n до m вхождений
* - 0 или больше вхождений
+ - 1 или больше вхождений
? - ни одного или 1 вхождение

Замена с регулярками:
def func(m):
    ... do smth with match object

p = re.compile(r'...')
p.sub(func, text_for_searching_and_replacement)

Разделить строку с помощью регулярных выражений:
re.split(r'[;,\s]\s*', line_for_splitting)

Пример применения:
s = 'Сегодня 9/04/2025. Завтра будет 09/10/2025.'
p = re.compile(r'(\d{1,2})/(\d{1,2})/(\d{4})')

print(p.sub(r'\3-\1-\2', s))

def date_transform(m):
    month, day, year = m.groups()
    if len(month) == 1:
        month = '0' + month
    return f'{year}-{month}-{day}'

print(p.sub(date_transform, s))

Словарь - пример не последовательности, а отображения. Доступ - по ключу, а не по индексу.

Создание словарей:
d = dict(name='Name', surname='Surname')
d = dict({'name': 'Name', 'surname': 'Surname'})
d = dict([('name', 'Name'), ('surname', 'Surname')])
d = dict([['name', 'Name'], ['surname', 'Surname']])

keys = ['name', 'surname']
values = ['Name', 'Surname']
kv = list(zip(keys, values))
d = dict(kv)

Правильное копирование (поверхностное и глубокое):
d1 = d.copy()

import copy
d1 = copy.deepcopy(d)

Доступ к элементам:
d[key]   # Error, если ключа key в словаре нет
d.get(key, default) - вернет default, если ключа в словаре нет

key in d  # есть ли в словаре d ключ key

Длина словаря:
len(d)

Добавление элемента:
d[new_key] = value

Обращение к элементу с default:
d.setdefault(key, default) - если key есть в словаре, то возвращается d[key], если нет, то выполняется d[key] = default и возвращается default
Пример:
>>> d
{'name': 'Anton'}
>>> d.setdefault('lastname', 'default')
'default'
>>> d
{'name': 'Anton', 'lastname': 'default'}
>>> d.setdefault('name', 'default_name')
'Anton'
>>> d
{'name': 'Anton', 'lastname': 'default'}

Обвление словаря другим словарем:
d.update(d1) - ключи из d1, которых нет в d добавляются в d со значениями из d1, а значения по общим ключам обновляются значениями из d1

Удаление элемента:
del d[key]
d.pop(key)  # возвращает значение словаря по ключу и удаляет ключ и значение из словаря
d.clear()   # полная очистка словаря

Перебор элементов словаря:

for key in d:
    d[key]

for key in d.keys():
    d[key]

for value in d.values():
    value

for key, value in d.items():
    print(key, value)

Множество - это неупорядоченный набор элементов

Операции над множествами (ключи словаря - тоже множество):
s1 | s2 - объединение
s1 & s2 - пересечение
s1 - s2 - разность
s2 - s1 - разность
s1 ^ s2 - симметрическая разность

s1 == s2 - равенство
s1 <= s2 - включение (все элементы s1 входят в s2)

Методы множств:
s.add(val) - добавление элемента
s.remove(val) - удаляет элемент, либо ошибка, если элемента нет
s.discard(val) - удаляет элемент, нет ошибки, если элемента нет
s.pop() - удаляет произвольный элемент и возвращает его
s.clear() - очищает множество
